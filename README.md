# 🏥 Clinic Management System

A desktop application developed in C# Windows Forms for managing patients, appointments, and clinic queues.

## Features
- Patient Registration
- Appointment Booking
- Queue Management
- Splash Screen
- Easy Navigation

## Technologies Used
- C#
- Windows Forms
- .NET Framework 4.7.2
- Visual Studio

## How to Run
1. Open .csproj in Visual Studio
2. Build Solution
3. Run Project
